- Integration by trig sub: usually scaffolded questions
	- $\int_{0}^{4} \frac{\sqrt{ x^{2}+16 }}{x}dx$ using the substitution $x = 4 \tan(\theta)$
	- $\int \sqrt{ 1 - 7 w^{2} }dw$ using $w = a \sin(\theta)$ for a suitable $a>0$
